SENSORY STUDIO - THIRD-PARTY COMPONENT NOTICES
============================================

This inventory covers components in the self-contained Release application
publish directories for Windows x64 and ARM64. Component presence was checked
against publish source items and the resulting files, not just direct package
references. It does not establish that every included component is exercised
by the application.

This two-experience source snapshot retains the original dependency versions
and supplier documents. Ambient MP3s, LiquidEther, and bubble/string audio and
exclusive thumbnails have been removed. Source-only sharing does not authorize
redistribution of the retained code, garden assets, or compiled payload.

The accompanying ThirdPartyNotices directory contains unmodified supplier
license and notice documents. Paths below are relative to that directory.
sources.csv records each document's package/version or download URL and SHA-256.
Supplier notice bundles are preserved in full and can describe additional
components not used by this application.

These documents apply to their respective components. They do not license
Sensory Studio's own source code, artwork, or audio, and do not constitute
legal, privacy, security, or release approval. The source-license decision
remains open. This inventory must not be treated as distribution clearance.

7. SCOPE AND EXCLUSIONS
-----------------------

The following resolved packages do not contribute distinct payload files to
the inspected publish item sets. Their relevant umbrella documents are
accounted for above; this is not a claim that their transitive dependencies
are absent:

  Microsoft.WindowsAppSDK         2.4.0
  Microsoft.WindowsAppSDK.Base    2.0.4
  Microsoft.WindowsAppSDK.Runtime 2.4.0
  Microsoft.WindowsAppSDK.ML      2.1.74

Build tooling is not application payload:

  Microsoft.Windows.SDK.BuildTools      10.0.26100.4654
  Microsoft.Windows.SDK.BuildTools.MSIX 1.7.251221100

Their tool-only notice documents are not represented as application runtime
notices. Likewise, Microsoft.WindowsAppSDK.WinUI's tools\NOTICE.txt covers
build tools rather than the inspected runtime payload.

Downloaded ASP.NET Core and Windows Desktop runtime packs are not included
merely because restore acquired them: the inspected application publishes
do not redistribute those framework packs. Removed legacy WPF, React, Vite,
and esbuild components are not part of the current application.

The previously hidden Pomodoro and Pulse Runner experiences have been removed.
Microsoft.Graphics.Win2D, used only by Pomodoro's renderer, is no longer a
dependency or part of either clean publish payload. Its previously unresolved
binary-license link is therefore not a requirement for the current payload.
This does not retroactively clear older binaries or historical source versions.

This inventory does not cover the installer engine, build-machine software,
separately installed Windows components, or optional future downloads.
Recheck any final installer/bootstrapper and release artifact separately.

MAINTENANCE
-----------

When dependencies, runtime patches, publish settings, or bundled assets change,
publish both architectures, inspect the actual payload and source items,
refresh supplier documents from the resolved packages, and update this
inventory and sources.csv together. Preserve complete supplier text and verify
copied files by SHA-256. A NuGet graph alone is not proof of runtime inclusion.

Keep this file and the entire ThirdPartyNotices directory with the application.
The project copies both into build and local publish output. This source-only
snapshot does not provide an installer or an approved binary release.
